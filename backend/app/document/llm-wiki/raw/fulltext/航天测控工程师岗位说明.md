航天测控工程师

岗 位 说 明 书

| 岗位名称 | 航天测控工程师 |
| --- | --- |
| 所属部门 | 测控通信系统部 |
| 汇报对象 | 测控系统总师 |

| 招聘人数 | 2人 |
| 工作地点 | 北京 |


# 二、岗位概述

航天测控工程师负责航天器测控通信系统的规划、设计、建设和运行维护工作。该岗位需要确保地面测控站与在轨航天器之间的通信链路稳定可靠，实现对航天器的精确跟踪、遥测数据接收和遥控指令发送，是保障航天任务成功的关键技术岗位之一。

# 三、岗位职责

- 负责航天测控系统方案设计与技术论证
- 开展测控链路预算分析、通信协议设计和信号处理算法开发
- 参与地面测控站的建设、调试与验收工作
- 执行在轨航天器的日常测控任务，监控航天器运行状态
- 开发和维护测控数据处理软件，实现遥测数据的实时处理与分析
- 参与重大航天发射任务的测控保障工作
- 跟踪国际测控技术发展动态，推动测控系统技术升级
# 四、任职要求

- 通信工程、电子信息工程、信号处理或相关专业本科及以上学历
- 5年以上航天测控或卫星通信系统工作经验
- 熟悉航天测控体制、通信协议和信号处理技术
- 掌握C/C++、Python等编程语言，具备软件开发能力
- 熟悉测控设备（天线、发射机、接收机等）的原理和操作
- 具有良好的问题分析与解决能力
- 能适应值班和出差要求
# 五、薪酬福利

- 完善的薪酬福利体系
- 五险一金及补充商业保险
- 值班补贴与出差补贴
- 技术培训与职业发展规划支持
- 定期健康体检
- 参与重大航天工程的荣誉感与成就感
