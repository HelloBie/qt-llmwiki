# 二、岗位概述

航天器总体设计师是航天器研制项目的技术核心负责人，负责航天器系统的总体方案设计、技术协调和系统集成工作。该岗位需要统筹各分系统的设计需求，确保航天器在功能、性能、可靠性、安全性等方面满足任务要求，是连接用户需求与各分系统设计团队的关键桥梁。

# 三、岗位职责

- 负责航天器总体方案设计，包括任务分析、系统架构定义、功能分配与接口设计
- 组织编制航天器总体技术方案，协调各分系统（结构、热控、电源、姿轨控、测控等）的设计需求
- 开展系统级仿真分析与优化，验证总体方案的可行性和可靠性
- 主持技术评审会议，组织解决研制过程中的重大技术问题
- 参与航天器总装、测试与发射任务的技术保障工作
- 跟踪国内外航天技术发展趋势，提出新技术应用建议
- 编写和审核各类技术文档，确保设计过程的可追溯性
# 四、任职要求

- 航空航天工程、飞行器设计或相关专业硕士及以上学历
- 8年以上航天器设计工作经验，3年以上总体设计经验
- 熟悉航天器各分系统的工作原理和技术特点
- 具备系统工程设计能力，熟练掌握CAD/CAE等设计工具
- 具有较强的项目管理能力和团队协调能力
- 具备良好的英文读写能力，能阅读和编写英文技术文档
- 具有完整型号研制经验者优先
# 五、薪酬福利

- 具有竞争力的薪酬体系（基本工资+项目奖金+年终奖）
- 五险一金及补充商业保险
- 带薪年假、探亲假等国家法定假期
- 定期健康体检
- 专业技术培训与学术交流机会
- 职称评定与职业发展通道
