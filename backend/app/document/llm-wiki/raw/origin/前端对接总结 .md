   共用传参格式
   前端工具节点统一按这个结构传：
   {
     "provider_id": "xxx",
     "provider_name": "xxx",
     "tool_name": "xxx",
     "tool_parameters": {
       "参数名": {
         "type": "mixed",
         "value": "实际值或变量值"
       }
     },
     "tool_configurations": {
       "配置名": {
         "type": "mixed或constant",
         "value": "配置值"
       }
     }
   }
   
   变量引用也可以这样传：
   {
     "type": "variable",
     "value": ["上游节点ID", "字段名"]
   }
   比如 
   {
     "type": "variable",
     "value": ["start", "input"]
   }
   共用响应格式
   所有生成文件类工具里的 files / file 数组元素都是这个结构：
   {
     "transfer_method": "tool_file",
     "url": "文件访问地址，可能是 MinIO URL 或 data URI",
     "type": "document/custom/image",
     "filename": "生成的文件名",
     "name": "生成的文件名",
     "mime_type": "文件 MIME 类型",
     "size": 12345
   }
   具体的每一个如何传参 与 响应的格式

   6. 工作流发布成工具
   {
     "provider_id": "builtin/workflow/test_zhang_workflow",
     "provider_name": "builtin/workflow/test_zhang_workflow",
     "tool_name": "test_zhang_workflow",
     "tool_parameters": {
       "input": {
         "type": "mixed",
         "value": "用户输入内容"
       },
       "input_file": {
         "type": "mixed",
         "value": {
           "transfer_method": "remote_url",
           "url": "https://example.com/test.pdf",
           "filename": "test.pdf",
           "name": "test.pdf",
           "type": "document",
           "mime_type": "application/pdf"
         }
       }
     },
     "tool_configurations": {}
   }
   详细解析如下 
   如果参数来自上游节点，前端可以这样传：
   {
     "provider_id": "builtin/workflow/test_zhang_workflow",
     "provider_name": "builtin/workflow/test_zhang_workflow",
     "tool_name": "test_zhang_workflow",
     "tool_parameters": {
       "input": {
         "type": "variable",
         "value": ["start", "input"]
       },
       "input_file": {
         "type": "variable",
         "value": ["start", "input_file"]
       }
     },
     "tool_configurations": {}
   }
   不同入参类型的传法
   文本参数：
   {
     "type": "mixed",
     "value": "文本内容"
   }
   数字参数：
   {
     "type": "mixed",
     "value": 72
   }
   单文件参数：
   {
     "type": "mixed",
     "value": {
       "transfer_method": "remote_url",
       "url": "https://example.com/a.pdf",
       "filename": "a.pdf",
       "name": "a.pdf",
       "type": "document",
       "mime_type": "application/pdf"
     }
   }
   多文件参数：
   {
     "type": "mixed",
     "value": [
       {
         "transfer_method": "remote_url",
         "url": "https://example.com/a.pdf",
         "filename": "a.pdf",
         "name": "a.pdf",
         "type": "document",
         "mime_type": "application/pdf"
       },
       {
         "transfer_method": "remote_url",
         "url": "https://example.com/b.pdf",
         "filename": "b.pdf",
         "name": "b.pdf",
         "type": "document",
         "mime_type": "application/pdf"
       }
     ]
   }
   下拉/枚举参数：
   {
     "type": "mixed",
     "value": "选中的值"
   }
   发布接口返回后，前端重点存这几个字段
   {
     "category": "workflow",
     "provider_id": "builtin/workflow/test_zhang_workflow",
     "provider_name": "builtin/workflow/test_zhang_workflow",
     "provider_type": "workflow",
     "tool_name": "test_zhang_workflow",
     "tool_label": "test_zhang_workflow",
     "paramSchemas": [
       {
         "name": "input",
         "type": "string",
         "required": true,
         "form": "llm"
       },
       {
         "name": "input_file",
         "type": "file",
         "required": true,
         "form": "llm"
       }
     ]
   }
   最简结论
   工作流工具:
   provider_id = builtin/workflow/{tool_name}
   provider_name = builtin/workflow/{tool_name}
   category = workflow
   tool_name = 发布时填写的工具调用名称
   
   tool_parameters:
   按发布工作流开始节点变量名传
   比如 input、input_file、query、file_list 等
   
   tool_configurations:
   通常为空，除非发布时后端额外定义了固定配置项
   响应： 
   工作流工具不是固定文件工具，它会把被调用工作流的最终输出规整成下面结构：
   {
     "success": true,
     "text": "优先提取工作流输出中的 text / answer / result / output",
     "outputs": {
       "text": "工作流最终文本输出",
       "其他字段": "其他工作流输出"
     },
     "json": {
       "workflow_app_id": "被发布的工作流ID",
       "workflow_type": "workflow",
       "tool_name": "工具调用名称",
       "outputs": {
         "text": "工作流最终文本输出",
         "其他字段": "其他工作流输出"
       },
       "success": true,
       "error": null
     },
     "files": [
       {
         "transfer_method": "tool_file或remote_url",
         "url": "文件地址",
         "type": "document/image/custom",
         "filename": "文件名",
         "name": "文件名",
         "mime_type": "MIME类型",
         "size": 12345
       }
     ],
     "file": {
       "transfer_method": "tool_file或remote_url",
       "url": "文件地址",
       "type": "document/image/custom",
       "filename": "文件名",
       "name": "文件名",
       "mime_type": "MIME类型",
       "size": 12345
     },
     "error": null
   }
   注意：工作流工具的 file 是第一个文件对象或 null，不是数组；上面 5 个固定插件工具里的 file 是数组。
   
   如果工作流没有文件输出：
   {
     "success": true,
     "text": "工作流输出文本",
     "outputs": {
       "text": "工作流输出文本"
     },
     "json": {
       "workflow_app_id": "workflow_app_id",
       "workflow_type": "workflow",
       "tool_name": "test_zhang_workflow",
       "outputs": {
         "text": "工作流输出文本"
       },
       "success": true,
       "error": null
     },
     "files": [],
     "file": null,
     "error": null
   }
   如果工作流执行失败：
   {
     "success": false,
     "text": "错误信息",
     "outputs": {},
     "json": {
       "workflow_app_id": "workflow_app_id",
       "workflow_type": "workflow",
       "tool_name": "test_zhang_workflow",
       "outputs": {},
       "success": false,
       "error": "错误信息"
     },
     "files": [],
     "file": null,
     "error": "错误信息"
   }
