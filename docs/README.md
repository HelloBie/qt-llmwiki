## 🛠️ 文档维护与演进规范

1. **持续同步原则（Living Documentation）**：
   - 当新增或调整 API 路由时，同步更新 [`04_接口设计文档_API.md`](./04_接口设计文档_API.md)；
   - 当调整数据表字段、索引或数据字典时，同步更新 [`03_数据库设计文档_DBD.md`](./03_数据库设计文档_DBD.md)；
   - 当扩展新的文件解析格式（如增加 EPUB / 音视频转写）或改变状态机时，同步更新 [`02_详细设计说明书_DD.md`](./02_详细设计说明书_DD.md)；
   - 当系统引入新的中间件、向量数据库或重构部署拓扑时，同步更新 [`01_概要设计说明书_总体设计.md`](./01_概要设计说明书_总体设计.md)。
2. **规范化引用**：
   - 代码内保留准确的方法 docstring 与类型注解，与设计文档保持 100% 一致。
